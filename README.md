# Tisícka slovíčok

Aplikácia na učenie 1000 základných anglických slov. Otvára sa cez `index.html`.

- Triedenie po 50 slovách (Viem / Váham / Nové), potom kartičky a písanie.
- Pokrok sa ukladá v prehliadači (localStorage).
- `zdroj/` obsahuje zoznam slov (`all.txt`) a šablónu stránky (`template.html`).
